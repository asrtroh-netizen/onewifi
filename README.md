## 🤔 为什么会有 OneWIFI？

模组其实很能干。

eSIM 能切、Wi‑Fi Calling 能打、短信能走 IMS……纸面上样样在线。

可一接到真实网络，它就偶尔开始“装傻”：

* 📞 明明支持 VoWiFi，注册就是不上；
* 💳 eSIM 能切卡，界面却不告诉你卡在哪一步；
* 🌍 海外卡能用，国内卡却要额外折腾；
* 🔧 昨天还好着，今天隧道超时、IMS 没回包；
* 🧐 日志一长串，论坛里考古到天亮。

然后大家开始：

```
AT+CFUN=1,1
再插一次 USB
换个节点
重启测试
再失败
```

最后异口同声：

> “到底哪里出了问题？” 🤨

OneWIFI 想做的事很简单：

**让模组用户看懂设备、能切卡、能走 Wi‑Fi Calling、能收发短信——在一个工作台里搞定。**

## 🌟 功能玩法

### 📟 设备

发现模组、看注册和信号、起停网络、重启、飞行模式。  
号码默认打成星号，想看完整的自己再打开——别在会议室投屏翻车。

### 💳 切卡

读 eUICC、下载 / 启用 / 禁用 Profile。  
卡策略按 ICCID 记，换卡不会串成「上一张的脾气」。

### 📶 Wi‑Fi Calling

走 ePDG / IMS。  
规矩写在前面：**电话、短信、数据永远比这条隧道优先。**  
VoWiFi 可以晚点研究，电话不能失踪。😂

### 💬 短信与保号

蜂窝和 IMS 都能收发。  
保号用来定时发短信或探公网 IP——是养号，不是扰人。

### 🧭 出口代理

给 VoWiFi 数据路径绑上游节点。  
自己的网关、自己的路由，别把家宽出口和漫游出口搞混。
