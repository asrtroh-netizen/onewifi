功能玩法

  • 设备 发现模组、看注册和信号、起停网络、重启、飞行模式。号码默认打星，需要时再自己打开。
  • 切卡 读 eUICC、下载 / 启用 / 禁用 Profile。卡策略按 ICCID 记，换卡不会串。
  • Wi-Fi Calling 走 ePDG / IMS。电话、短信、数据永远比这条隧道优先。
  • 短信与保号 蜂窝和 IMS 收发；保号用来定时发短信或探公网 IP，不是拿来扰人。
  • 出口代理 给 VoWiFi 数据路径绑上游节点。自己的网关、自己的路由。
